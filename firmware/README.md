# Firmware

Hier wird später die ESP32-Firmware abgelegt.

## Aktueller Stand

Noch keine konkrete Hardware ausgewählt.

Nach Auswahl des Controllers und der Sensoren wird entschieden, ob ESPHome oder eine eigene Firmware verwendet wird.

## Geplante Funktionen

- WLAN-Konfiguration
- Sensorinitialisierung
- zyklische Messung
- Plausibilitätsprüfung
- Home-Assistant-Anbindung
- Fehlerbehandlung
- automatische WLAN-Wiederverbindung
- OTA-Updates

## Noch offen

- ESP32-Modell
- Sensoren
- Pinbelegung
- Messintervalle
- Versorgungsspannung
- Gehäuse
- Montageort
